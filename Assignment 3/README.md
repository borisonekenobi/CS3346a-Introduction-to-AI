## Contract

- `fit_nb(X, y, alpha=1.0)` returns the supplied `NBModel` dataclass.
- `model.priors[c]` is the empirical class prior; `model.p_one[c][j]` is the
  smoothed probability of feature j being 1 given class c.
- `posterior_one(model, x)` returns the normalized probability of class 1.
- Support any positive number of features and any positive smoothing alpha.
  Both classes occur in valid training input. Do not modify the supplied inputs.
- Use standard-library loops/counting and log-likelihood calculations. Do not
  call a prebuilt classifier, hardcode the supplied data, or replace the driver.
- Input validation and stable normalization are supplied in `a3_support.py`.

## Data and experiment protocol

All rows are fixed, hand-authored synthetic teaching cases. No external data is
used. No random operation is used, so a random seed is not applicable. Distinct
case IDs with the same feature vector represent different cases, not duplicated
raw messages. Train only on train.csv. Choose the threshold from the three stated
candidates using validation.csv. Freeze it before reporting test.csv results.
Test labels are included for reproducibility, not for tuning. These are not a
sealed blind test or evidence of real-world performance.

Feature order: x1 mentions outage; x2 mentions urgency; x3 mentions access failure.
Label 0 means Routine; label 1 means Review and is the positive class.
Select minimum validation cost 4*FN+FP; exact ties choose the largest threshold.
Predict Review when probability >= threshold.
